# Atomix Round 22 — Plan D (player extras, edit details and artwork) and the v0.20.0 release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Kodi's player habits — playback speed, audio and subtitle delay remembered per title, chapters — and admins editing a title's details and artwork with locks that refresh and Fix match leave alone; then v0.20.0.

**Architecture:** Migration 22 adds `play_settings` (per profile and title) and `items.locked_fields`. Audio delay is server-side: the playback plan gets `audioDelay`, `buildFfmpegArgs` reads the audio from a second, `-itsoffset` input (copied, not converted), and a file that would play as-is is remuxed instead. Speed and text-subtitle delay are browser-side (`playbackRate`, cue times). Burned-in picture subtitles get their delay the same way as audio (a second input). Chapters come from the stored probe (`media.chapters`), re-read once for items probed without them. Edit details is an admin route writing chosen fields and adding them to `locked_fields`; `MetadataManager.refresh` keeps locked fields; artwork comes from TMDB's image lists, an upload (checked by its bytes) or an address (downloaded once).

**Tech Stack:** Node ≥ 22.13, `node:sqlite`, ffmpeg/ffprobe; plain ES-module browser JS; `node:test`; Playwright devtools.

**Spec:** `docs/superpowers/specs/2026-10-15-atomix-v020-design.md` (sections 8–9; Migrations 22). Builds on Plans A–C.

## Global Constraints

- Speed: settings menu → 0.5 / 0.75 / 1 / 1.25 / 1.5 / 2 (`playbackRate`, `preservesPitch`); `[` / `]` step; not for Live TV at the live edge (offered when rewound); back to 1× for the next title.
- Audio delay: −5…+5 s in 0.1 s; a restart of the stream at the current time with `-itsoffset` on the audio input (copied, not converted; a file playing as-is becomes a copy with the shift); remembered per profile and title (`play_settings`: profile_id, item_id, audio_delay, subtitle_delay).
- Subtitle delay: subtitles menu → −10…+10 s in 0.1 s; `Z` / `X` step; text tracks shifted in the browser; burned-in subtitles restart with the offset; remembered per profile and title.
- Chapters: from `media.chapters`; items probed before chapters were stored are re-read once; ticks on the seek bar, a **Chapters** menu (name, time, preview picture), PageUp / PageDown to the previous / next chapter (Live TV keeps PageUp/PageDown for channels).
- Edit details (admins): title page → **Edit details** beside Fix match. Films/shows: title, sort title, original title, year/release date, plot, tagline, genres, studio, age rating; episodes: title, season/episode number, aired date, plot; albums: title, album artist, year, genres; artists: name, biography. Artwork: TMDB posters/backdrops/logos, upload (≤ 10 MB, JPEG/PNG/WebP, checked by its bytes), or an address (downloaded once). Edited fields are locked (`items.locked_fields` JSON list) so refresh and Fix match leave them; each shows a lock with **Unlock**.
- No dependencies; older themes pixel-identical; TV-remote friendly; no browser dialogs; Kids never see admin controls.

## Review Focus

1. **An audio delay on a file that would play as-is, then a seek** — the shift survives the seek (each restart keeps it) and the picture isn't converted (Task 1 test `a delayed file is copied, not converted, and keeps its delay from any start`).
2. **Speed 1.5× in a Watch together room** — the room's drift check doesn't fight it: speed changes are refused in a room with a sentence (Task 2 UI check `speed is off in a room`).
3. **A locked title through Fix match** — the new match fills everything else but the locked fields keep their edited values (Task 4 test `Fix match keeps locked fields`).
4. **An upload that's a renamed PDF or 11 MB** — refused with a sentence, nothing stored (Task 5 test `uploads are checked by their bytes`).
5. **A title with chapters but a Kids profile / no preview pictures** — the Chapters menu still lists names and times without pictures (Task 3 UI check).
