# Atomix Round 23 — Plan D (tidy-up: household, player and editing; v0.21.0) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the v0.20 leftovers for Watch together, Quick Connect, Activity, Stats, the player and Edit details; decide the two items declined last round (casts carry the delays; moving an episode between seasons); then release v0.21.0.

**Architecture:** Small changes in the files that own each item, one test per item that fails first. No new tables: the per-play time zone is worked out from the viewer's IANA zone (Node's Intl) at each play's own time.

**Tech Stack:** Node ≥ 22.13 (`node:test`, `node:sqlite`, Intl), ffmpeg; plain ES-module browser JS; Playwright devtools.

**Spec:** `docs/superpowers/specs/2026-10-16-atomix-v021-design.md` section 4 (and Testing). Items mapped from the code (v0.20 reviews' deferred minors).

## Global Constraints

- Every item: a test that fails first (Node where server-side, a `devtools/v021-ui.mjs` check where it is a page); unit suite green at each task's end.
- Copy (exact): "Season 2 already has episode 3." (numbers from the edit); "That address isn't a picture." ; "1 hour" / "N hours"; "Choose who is watching first." (428).
- Older themes pixel-identical (`oldthemes-compare` "all pages match"); `v020-ui`, `a11y-ui`, `live-ui`, `music-ui`, `cast-ui` stay green.
- No dependencies; no Kodi GPL code; no provider URLs/tokens to the browser or logs.

## Review Focus

1. **A Watch together room with a converted member and a Kids member** — next episode only the show's own; the Kids member dropped when its rules (as they are now) refuse it (Task 1 tests).
2. **A cast with an audio or subtitle delay** — the TV hears and shows them shifted as the browser would (Task 5 tests).
3. **An episode moved to another season** — no duplicate number, no empty season left behind, the show's lists right (Task 4 test).
4. **Leaving the player right after changing a delay or the speed** — saved; a zap returns to 1× (Task 3 checks).
5. **Stats across a daylight-saving change** — each play in the hour it happened locally (Task 2 test).
