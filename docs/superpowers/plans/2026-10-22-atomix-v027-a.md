# Atomix v0.27.0 Plan A: a secure (HTTPS) address at home

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Atomix can serve an HTTPS address beside its HTTP one, with either a Tailscale certificate or its own home certificate. An admin sets it up from Settings, and a phone on the plain address is pointed to the secure one when an encrypted channel needs it.

**Architecture:**
- **`src/tls/`** holds four modules:
  - `x509.js`: a DER certificate writer on `node:crypto` keys;
  - `own.js`: the home CA, the server certificate and the phone downloads;
  - `tailscale.js`: finding and asking the Tailscale CLI;
  - `server.js`: `HttpsManager`, which runs the second listener with the app's own request handler and swaps certificates in place.
- **`app.js`** hands its handler to `HttpsManager`. `/api/status` carries `secureUrl`.
- **The browser** gets a Settings card, and the encrypted-channel path gets a "needs the secure address" sentence.

**Tech Stack:** `node:https`, `node:tls`, `node:crypto` (EC P-256, `crypto.sign`), `node:child_process` `execFile`. Node's test runner; Playwright checks in `/home/claude/devtools`.

**Spec:** `docs/superpowers/specs/2026-10-22-atomix-v027-phone-live-tv-design.md` (§1, Global constraints, Verification).

## Global Constraints

- **No DRM circumvention.** Keys and tokens never reach a browser, a TV or a log. Plan A adds no DRM paths.
- **The HTTP address (`:8787`) and everything on it stay as they are.** HTTPS is an extra listener, and only with `httpsMode` other than `off` (default `off`).
- **No npm install, no build step, no new libraries.** Certificates are built with `node:crypto` and a small DER writer.
- **Older themes stay pixel-identical:** `node /home/claude/devtools/oldthemes-compare.mjs compare` → "all pages match".
- **Each file in its own style.** Settings is a `render(el)` view built with `h()`.
- **Node ≥ 22.13. Windows is the main host:** paths, the Tailscale binary location, permissions.
- **Copy, verbatim:**
  - "Tailscale isn't installed on this computer"
  - "Tailscale isn't signed in"
  - "Turn on HTTPS certificates in Tailscale's admin page (DNS → HTTPS Certificates)"
  - "Run this once as administrator: `<command>`"
  - "Encrypted channels need Atomix's secure address on this device"
  - "Ask the admin to turn on the secure address (Settings → Server)"
- **Values:**
  - `httpsPort` default **8443**, env `ATOMIX_HTTPS_PORT`;
  - certificates in `<data>/certs/`;
  - renew under **30 days** left;
  - CA **10 years**, server certificate **825 days**;
  - keep-alive 65 s / headers 66 s.
- **Process:** never `pkill -f`; browser suites run one after another; no git in the cloud copy (the ledger records each task).

## Review Focus

1. **The HTTPS port already in use** (another program, or Atomix's own HTTP port). Atomix keeps running on HTTP, and the card says "Port 8443 is in use; pick another port". Test: Task 3, `a busy HTTPS port is a sentence, not a crash`.
2. **The PC's network address changes** (DHCP, a new Wi-Fi). The own certificate is remade with the new address from the same CA, without a restart, so phones don't reinstall anything. Test: Task 1, `a changed address remakes the server certificate from the same CA`.
3. **`tailscale` hanging** (daemon stopped, network down). The call gives up after 20 s with a sentence; start-up isn't held. Test: Task 2, `a hung tailscale gives up with a sentence`.
4. **Switching modes back and forth** (own → tailscale → off → own) while the listener is up. One listener, the right certificate each time, nothing left listening after `off`. Test: Task 3, `switching modes keeps one listener with the right certificate`.
5. **A request on the HTTPS address behaves like one on HTTP:**
   - same routes and sign-in;
   - the session cookie is `Secure` on HTTPS;
   - CSRF origin checks pass for the HTTPS origin;
   - the SPA page loads.

   Test: Task 3, `the HTTPS address serves the same app with a Secure cookie`.

### Task 1: The certificate writer and Atomix's own certificate

**Files:**
- Create: `src/tls/x509.js`, `src/tls/own.js`
- Test: `test/tls-own.test.js`

**Interfaces:**
- Produces:
  - **`x509.js`** — `makeCertificate({ subjectCN, issuerCN, publicKey, signingKey, serial, notBefore, notAfter, ca, san }) → { der: Buffer, pem: string }`.
    - `publicKey` and `signingKey` are `KeyObject`s (EC P-256); `serial` is a positive 16-byte Buffer.
    - `san` is `{ dns: string[], ip: string[] }` or null.
    - Signature `ecdsa-with-SHA256` (OID 1.2.840.10045.4.3.2) via `crypto.sign('sha256', tbs, { key, dsaEncoding: 'der' })`.
    - Times: UTCTime before 2050, GeneralizedTime from then on.
    - Extensions:
      - `basicConstraints` (critical; `cA` true only for `ca`);
      - `keyUsage` (critical; CA: keyCertSign + cRLSign; leaf: digitalSignature);
      - `extendedKeyUsage serverAuth` (leaf only);
      - `subjectAltName` (leaf);
      - `subjectKeyIdentifier` (SHA-1 of the key bits);
      - `authorityKeyIdentifier` (leaf: the CA's).
  - **`own.js`**:
    - `lanAddresses(interfaces = os.networkInterfaces()) → string[]`: IPv4, not internal, not 169.254/16.
    - `ensureOwnCertificates({ dir, serverName, hostname = os.hostname(), addresses = lanAddresses(), now = new Date() }) → { key: string, cert: string, caPem: string, caDer: Buffer, notAfter: Date, changed: boolean }`.
      - Files: `own-ca.key`, `own-ca.crt`, `own.key`, `own.crt`, `own.json` `{ san }`; keys written with mode 0o600.
      - CA "Atomix home CA (<serverName>)", 10 years, kept forever once made.
      - Server certificate: 825 days, SAN dns `[hostname, `${hostname}.local`, 'localhost']`, ip `[...addresses, '127.0.0.1']`.
      - Remade from the same CA when the SAN set differs or under 30 days are left.
      - `cert` is the leaf PEM followed by the CA PEM.
    - `mobileconfig(caDer, { serverName }) → string`: an Apple configuration profile.
      - `PayloadType` `com.apple.security.root` holding the DER as `<data>`.
      - Outer `PayloadType Configuration`, `PayloadDisplayName` "Atomix home certificate".
      - UUIDs made from a SHA-256 of the DER, so the profile is stable.

### Task 2: Tailscale

**Files:**
- Create: `src/tls/tailscale.js`
- Test: `test/tls-tailscale.test.js` (with a fake `tailscale` script written to a temp folder by the test)

**Interfaces:**
- Produces:
  - `findTailscale({ env = process.env, platform = process.platform, exists = fs.existsSync, which }) → string | null`. The order is:
    1. `env.ATOMIX_TAILSCALE`;
    2. `tailscale` on PATH (`which('tailscale')`, a PATH search);
    3. `C:\Program Files\Tailscale\tailscale.exe` (win32);
    4. `/Applications/Tailscale.app/Contents/MacOS/Tailscale` (darwin).
  - `class TailscaleError extends Error { command?: string }`.
  - `tailscaleCertificate({ bin, dir, run = runFile }) → Promise<{ name, certFile, keyFile }>`.
    - It runs `status --json`:
      - `BackendState !== 'Running'` → "Tailscale isn't signed in";
      - `name = Self.DNSName` without the trailing dot;
      - `CertDomains` missing or without `name` → "Turn on HTTPS certificates in Tailscale's admin page (DNS → HTTPS Certificates)".
    - Then `cert --cert-file <dir>/ts.crt --key-file <dir>/ts.key <name>`.
    - Errors matching `/access is denied|permission denied|administrator|must be run as root|operation not permitted/i` → `TailscaleError("Run this once as administrator: " + command)`, with `command` the quoted command line.
    - Other errors → their first stderr line.
    - `bin` null → "Tailscale isn't installed on this computer".
  - `needsRenewal(certPem: string | null, now = new Date()) → boolean`: true when unreadable or under 30 days left.
  - `runFile(bin, args) → Promise<{ stdout, stderr }>`: `execFile` with `timeout: 20_000`, `windowsHide: true`. A timeout rejects with "Tailscale didn't answer".

### Task 3: The HTTPS listener, settings, status and the phone downloads

**Files:**
- Create: `src/tls/server.js`
- Modify:
  - `src/app.js` (the handler is a named function given to both servers; start/stop; `settings.onChange`; the `/tls/` routes);
  - `src/config.js` (`httpsPort` from `HTTPS_PORT`);
  - `src/settings.js` (`httpsMode: 'off'`, `httpsPort: 8443`; `CHOICES.httpsMode`; `RANGES.httpsPort [1, 65535]`);
  - `src/api/admin.js` (`PATCH /api/admin/settings` checks `httpsPort !== config.port`; `GET /api/admin/https`);
  - `src/api/account.js` (`/api/status` `secureUrl`).
- Test: `test/tls-server.test.js`

**Interfaces:**
- Consumes:
  - Task 1's `ensureOwnCertificates`, `mobileconfig`;
  - Task 2's `findTailscale`, `tailscaleCertificate`, `needsRenewal`, `TailscaleError`.
- Produces:
  - **`class HttpsManager`**:
    - `constructor({ handler, settings, config, log, dataDir, tailscale = { find: findTailscale, certificate: tailscaleCertificate }, now })`.
    - `apply() → Promise<HttpsState>`: start, stop or re-key the listener per `httpsMode` and the port.
      - A port is `config.httpsPort ?? settings httpsPort`. `0` is allowed from config, for tests.
      - Re-keying uses `server.setSecureContext()`.
      - It never throws: a failure becomes the state's `sentence`.
    - `state() → HttpsState`, where `HttpsState = { mode, port, listening: boolean, secureUrl: string | null, sentence: string | null, command: string | null, name: string | null }`.
    - `renewSoon()`: a daily timer (`unref`) that calls `apply()` when `needsRenewal`.
    - `close() → Promise<void>`.
    - `serveCa(req, res, url) → boolean`:
      - `/tls/atomix-home-ca.crt` (DER, `application/x-x509-ca-cert`, `Content-Disposition: attachment; filename="atomix-home-ca.crt"`);
      - `/tls/atomix-home-ca.mobileconfig` (`application/x-apple-aspen-config`);
      - only in `own` mode; otherwise 404.
  - **`secureUrl`:**
    - `tailscale`: `https://<name>:<port>`;
    - `own`: `https://<first lanAddresses() entry, else 'localhost'>:<port>`;
    - only while `listening`.
  - A busy port → sentence `Port <port> is in use; pick another port`.
  - **`GET /api/admin/https`** (admin) → `HttpsState` plus `{ own: { caDownload: '/tls/atomix-home-ca.crt', profileDownload: '/tls/atomix-home-ca.mobileconfig' } | null }`.
  - **`GET /api/status`** → `secureUrl` (anyone, null when off). It's only an address.
  - **`PATCH /api/admin/settings`** with `httpsMode` / `httpsPort` → `core.https.apply()`. The answer comes once it has run.
