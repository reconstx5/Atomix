# Atomix v0.24.0 Plan A — Faster artwork Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Orbit fetches every picture at about the size it is shown, from smaller copies Atomix makes once with ffmpeg and keeps. The first things on screen load first, and the page's scripts are fetched early.

**Architecture:**
- A new `src/library/thumbs.js` owns the copies: the size ladders, making copies with ffmpeg, a small queue, falling back to the original, and housekeeping.
- Every place that sends a picture file goes through one `sendPicture()`, which honours `?w=` and `Accept`.
- On the client, a pure `public/js/sized.js` turns an Atomix picture address into `src`/`srcset`/`sizes`. It is used only when Orbit is the layout, so the older themes keep the full-size originals.
- `src/http/page.js` serves `index.html` with `<link rel="modulepreload">` for the core scripts and a module graph, so a view's scripts can be fetched early too.

**Tech Stack:** Node ≥ 22.13, ffmpeg (`libwebp` when present), `node:test`, plain ES modules, Playwright devtools (outside the repo). No dependencies.

**Spec:** `docs/superpowers/specs/2026-10-19-atomix-v024-ui-design.md` (§1).

## Global Constraints

- Node ≥ 22.13, `node:sqlite`, ffmpeg; plain ES-module browser JS with no build step; **no dependencies**.
- Older themes stay pixel-identical: `node /home/claude/devtools/oldthemes-compare.mjs compare` → "all pages match". Only Orbit asks for sized copies.
- Kids profiles never see admin data, nor any title outside their rules. A sized picture goes through the same `requireItem` / `canSee` checks as today.
- Size ladders (from the spec):
  - posters and square art: 200, 300, 450, 600;
  - backdrops and stills: 480, 960, 1280, 1920;
  - logos: 400, 800.
- A copy is never larger than its original.
- Copies use WebP when the request `Accept`s `image/webp` and ffmpeg has `libwebp`, else JPEG. Logos keep transparency (WebP with alpha, else PNG).
- At most 2 resizes at once, with the same copy sharing one job. After about 1.5 s the request gets the original. A failure is remembered for 1 hour.
- Cache limit `thumbCacheMB`, default 2048. A daily sweep runs.
- An artwork address with `?v=` is sent with `Cache-Control: private, max-age=31536000, immutable`.
- Never `pkill -f`; kill by PID. Never `rm -rf` with a cd plus a relative glob.

## Review Focus

1. **An original smaller than the asked size** (a 300-px poster asked at 600). The original is sent, never enlarged. Test: Task 1, `a copy is never bigger than its original`.
2. **A broken picture, or no ffmpeg.** The original is sent with no 500 error, and ffmpeg isn't run again for that picture within the hour. Test: Task 1, `a picture ffmpeg can't read falls back to the original, and isn't tried again for an hour`.
3. **A cold cache with a Home full of new posters** (10+ requests at once). No more than 2 ffmpeg runs at a time, and no request waits much past 1.5 s. Test: Task 1, `ten requests at once: two resizes at a time, the rest get the original after the wait`.
4. **An original replaced** (artwork changed in Edit details, Refresh info). The next request gets a new copy, never the old one. Test: Task 1, `a changed original gets a new copy`.
5. **A Kids profile asking for a sized picture of a title it can't see.** It gets 404, as for the full-size one. Test: Task 1, `a sized picture follows the viewer's rules`.

**Interfaces:**
- Produces, from `src/library/thumbs.js`:
  - `export const LADDERS = { poster: [200, 300, 450, 600], square: [200, 300, 450, 600], backdrop: [480, 960, 1280, 1920], logo: [400, 800] }`.
  - `export function snapWidth(type, w) → number|null`: the smallest ladder step ≥ `w`, or the top step if `w` is above it. `null` for a missing or non-numeric `w`, or `w ≤ 0`. Type `square` is used for album art, `backdrop` for stills and backdrops.
  - `export class Thumbs`:
    - Constructor: `{ config, tools, maxJobs = 2, waitMs = 1500, failMs = 3_600_000, now = Date.now, run = probe.run }`.
    - `async picture(file, { type, width, webp }) → { file, contentType }`. It returns the copy, or the original's own file and type when:
      - there is no width;
      - the original is no wider than the snapped width (read with `src/books/image-size.js`);
      - the copy failed within the hour;
      - the copy isn't ready within `waitMs`.
    - Copies are stored as `cacheDir/thumbs/<sha1(path)>/<mtimeMs>-<size>-<w>.<webp|jpg|png>`, with a `source` file in the same folder holding the original's path (used by Task 2).
    - The `jobs` map is keyed by output file; `active` is a count with a waiting list.
  - `export async function sendPicture(core, ctx, file, { type, cacheControl })`: reads `ctx.query.w` and `ctx.req.headers.accept`, gets `core.thumbs.picture(…)`, and sends it with `sendFile`.
    - Adds `Vary: Accept` when a width was asked.
    - Uses `private, max-age=31536000, immutable` when `ctx.query.v` is present, else the given `cacheControl`.
    - Returns `sendFile`'s result.
- ffmpeg arguments:
  - `['-hide_banner', '-loglevel', 'error', '-nostdin', '-y', '-i', file, '-vf', `scale=${w}:-2:flags=lanczos`, '-frames:v', '1', …]`.
  - Then one of: WebP `['-c:v', 'libwebp', '-quality', '80']` (logos also `-pix_fmt yuva420p`); JPEG `['-q:v', '3']`; PNG none.
  - Written to `<out>.part` and then renamed.

**Interfaces:**
- Produces, from `public/js/sized.js`:
  - `export const LADDERS`, the same values as the server's. A test checks they match `src/library/thumbs.js`.
  - `export function isArtworkUrl(url) → boolean`: `/api/items/<id>/image/<type>` or `/api/collections/<id>/image/<type>`, with or without a query.
  - `export function sizedAttrs(url, type, { orbit, eager = false, width = null }) → { src, srcset?, sizes?, fetchpriority? }`.
    - Not Orbit, or not an artwork address: `{ src: url }`.
    - Otherwise:
      - `src` is the address with `w=` of the type's middle step;
      - `srcset` lists every step as `<url>&w=<n> <n>w`;
      - `sizes` is `auto, <fallback>`, where the fallback is poster `200px`, square `200px`, landscape/backdrop-card `340px`, logo `500px`.
    - Eager images get the plain fallback instead (`sizes=auto` needs lazy).
    - With `width` (a known shown width × devicePixelRatio, for backdrops and logos), `src` is the snapped size and there's no `srcset`.
- `setBackdrop(url)` uses `sizedAttrs(url, 'backdrop', { orbit, width: innerWidth * devicePixelRatio })`. The hero's backdrop image gets `fetchpriority="high"`.

**Interfaces:**
- Produces:
  - `export function moduleGraph(publicDir) → Record<string, string[]>`: each `public/js/**/*.js` file (relative path) mapped to its static `import … from './x.js'` / `export … from` targets, resolved to `/js/...` paths. Dynamic `import()` is not followed.

    Built once at start, and again in dev when `index.html` or a script's mtime changes (checked at most every 2 s). Sent with `Cache-Control: no-cache` and the ETag, with a 304 when `If-None-Match` matches.
  - `public/js/app.js`: `preloadModules('/js/views/x.js')` adds one `<link rel="modulepreload">` per module in that view's graph that isn't already linked.
