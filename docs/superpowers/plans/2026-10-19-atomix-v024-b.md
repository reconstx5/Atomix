# Atomix v0.24.0 Plan B — A clearer menu Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** In Orbit, every menu entry can be told apart at a glance, and Search and Settings are always on screen. The phone gets a dock that fits a 360-px screen, with a More panel, and a profile pill that gets out of the way while you scroll.

**Architecture:**
- **Icons.** New icons are added to `dom.js`'s set. A pure `orbitLibraryIcon(lib)` in `orbit-rules.js` picks a library's icon (tested in Node), and `shell.js` uses it. The older themes keep `libraryIcon()`, so they stay pixel-identical.
- **Recordings flag.** The server marks the Live TV recordings library (`recordings: true` on `/api/libraries`), so it can get its own icon.
- **The rail.** `renderOrbitNav` splits the glass menu into a scrolling list (`ul.orbit-list`) and a pinned group (`ul.orbit-pinned`: Search, the divider, Settings). Both are inside the same `.orbit-menu` element, so `nav.js`'s linear Up/Down already crosses between them in DOM order.
- **The phone.** CSS keeps only the entries marked `orbit-dock`, and turns both lists into `display: contents`, so `order` arranges Home, Search, the libraries and More in one row. More opens a native `<dialog>` built with `openDialog`.
- **The pill.** A pure `pillShown()` rule decides when the pill hides; `app.js` applies it as `html.pill-hidden`.

**Tech Stack:** plain ES modules, CSS, `node:test`, Playwright devtools (outside the repo). No dependencies.

**Spec:** `docs/superpowers/specs/2026-10-19-atomix-v024-ui-design.md` (§2).

## Global Constraints

- Plain ES-module browser JS with no build step; **no dependencies**. All icons are new, drawn for Atomix in the same 24-unit line style as `dom.js`'s set (no copied icons, no Kodi GPL code).
- Older themes stay pixel-identical: `node /home/claude/devtools/oldthemes-compare.mjs compare` → "all pages match". The new icons, rail layout, dock and pill behaviour are Orbit's alone: older themes keep `libraryIcon()` and their nav markup.
- Icons, per the spec:
  - Audiobooks: headphones over a book.
  - Books: an open book.
  - Comics: a speech bubble.
  - Podcasts: a microphone.
  - TV Shows: a TV.
  - Recordings: a TV with a record dot.
  - Live TV: a broadcast mast.
  - Movies, Music, Lists, Downloads and Add-ons keep theirs.
- Search and Settings are pinned at the bottom of the rail below a divider, on screen at 1080p and 720p. Up from the pinned group goes into the list, and Down from the list's end goes into the pinned group.
- The phone dock is Home, Search, the first three libraries in menu order, and More. It never scrolls sideways and fits 360 px.
- More is a dialog with every entry: all libraries, Lists, Live TV, Downloads, Add-ons and Settings (each only when it is shown today). Focus moves into it, and Back or Escape closes it.
- The pill slides away while scrolling down. It returns on any scroll up and at the top of the page, and the cluster's buttons go with it. Reduced motion shows and hides it without sliding.
- Every entry keeps its accessible name and the current-page marker. Kids profiles see only what they see today (the lists of entries are unchanged, only arranged).
- The cloud copy has no git: each "Commit" step is a ledger line naming the change. Never `pkill -f`; kill by PID.

**Interfaces:**
- Produces: `pillShown({ y: number, lastY: number, shown: boolean }) → boolean`. It returns true at the top (`y <= 8`). Otherwise it returns false once `y > lastY + 4` (scrolling down) and true once `y < lastY - 4` (any scroll up), and keeps `shown` within that 4-px dead band.
- Produces: the class `html.pill-hidden`. It is toggled only when Orbit is the layout and the frame query does not match, and cleared on every route render.
